# NEXORA

An AI-powered personal life-management platform.

## Vision
NEXORA brings tasks, goals, schedules, and an AI companion into one calm, intelligent workspace — helping people make meaningful progress.

## Tech stack
- Next.js App Router
- React
- TypeScript
- CSS

## Getting started
```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the app.
